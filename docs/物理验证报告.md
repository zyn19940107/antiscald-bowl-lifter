# 物理可行性验证报告（V2 加高把手 · 双夹联锁取碗器）

> 方法：刚性体静力学 + 材料力学闭式校核 + 平面框架有限元（自编 2D beam FE）求解环形钢圈在工作载荷下的径向变形/应力。
> 工况：碗＋食物 1.2 kg（W = 11.77 N），结构校核取安全系数 3.0；钢-陶瓷摩擦系数 μ = 0.20。

## 1. 输入与几何

| 项 | 值 |
|---|---|
| 碗 | 碗口 φ173.6 / 碗腰 φ121.8 / 高 82.8 mm |
| 碗身锥面（夹持段）半角（相对竖直） | ψ = 37.2° |
| 钢圈 | 双钢丝 φ3.2，内缘 φ121.8，接触高度距碗底 45.4 mm |
| 加高把手 | 握点 R174 / Z172 mm（环平面以上 172 mm） |
| 材料 | 304 弹簧钢丝（Rp0.2 取 1200 MPa）、304 管 φ6×0.8 |

## 3. 安装工况（控制工况）

- 要把 C 形环套过碗口，环口需要张开 **51.8 mm**（每边约 25.9 mm）。
- 对应的钢丝表面曲率应变变化：**0.75%**；304 弹簧钢丝的弹性应变极限约 0.6~0.9% —— 处于临界。
- 按开口环（Castigliano）估算，张开力约 **499 N（≈51 kg 力）** —— 远超单人/双手舒适施力范围（一般 ≤100~150 N）。
- **结论：V2 的"从锅口放入、套过碗沿"在 φ3.2 双钢丝下不可行**；V1 的"从碗腰水平靠近"不需要跨碗沿，所以没有这个问题。
- **解决方向**（任选其一或组合）：

| 线径 | 自由内径 | 需张开量 | 估算张开力 |
|---|---|---|---|
| φ3.2 | φ122 | 56.2 mm | 585 N（≈60 kgf） |
| φ3.0 | φ122 | 56.2 mm | 508 N（≈52 kgf） |
| φ2.8 | φ130 | 48.1 mm | 308 N（≈31 kgf） |
| φ2.5 | φ122 | 56.2 mm | 344 N（≈35 kgf） |
| φ2.5 | φ145 | 33.2 mm | 121 N（≈12 kgf） |
| φ2.8 | φ150 | 28.3 mm | 118 N（≈12 kgf） |
| φ2.2 | φ155 | 23.3 mm | 53 N（≈5 kgf） |

- 其他做法：① 实际安装用"先斜插一侧、再滚压过碗沿"的手法（以锅沿/碗沿为支点，所需张开量远小于对称张开）；② 把 V2 做成"可开合铰链版"（一侧铰接、一侧挂钩），彻底避开弹性张开。本动画为讲清原理，把张开处理成对称弹性变形。

## 4. 稳定性（为什么必须两只）

- 单只夹子：手柄（握点距碗心 174 mm）与碗重力形成力偶，碗的重心必须移到握点正下方才可能平衡 → 需要的倾角约 **54°**，而碗口几何允许的倾角只有约 **37°** → 单夹必然翻倒/滑脱（与用户实际体验一致）。
- 两只夹子：双手在碗两侧对称上提，力偶互相抵消（净力矩 0），端头互锁成整环 → 稳定。

## 5. 3D 打印版（PETG/PA12）

- 打印环（6×7 mm 截面，PETG）的弯曲刚度只有钢制双钢丝的约 1/60（EI：0.36 vs 22.2 N·m²）。
- 安装张开所需的表面应变约 **1.4%**：PETG 屈服应变 ~2.5%，PA12 ~6% → **PA12/PA-CF（SLS）可反复使用；PETG 仅适合偶尔/轻载**。
- 打印立管（12×9 mm，PETG）在 SF=3 下的弯曲应力仅 2.7 MPa、挠度 2.4 mm → 打印件强度不是问题，**C 形环的刚度和蠕变才是限制**。
- M4 销钉单剪应力可忽略（0.7 MPa）→ 打印版关节用 M4 螺丝完全够用。

## 6. 结论与剩余风险

1. **承载/楔紧/稳定性：可行**。工作载荷下钢圈几乎不变形（微米级），几何锁 + 孔钩互锁成立；两只夹子对称受力，单夹的翻倒问题被消除。
2. **安装张开是控制工况，且是 V2 的主要工程风险**：φ3.2 双钢丝跨过 φ173.6 碗口需约 500 N 张开力，不具手工可操作性；应将线径降至 φ2.5–2.8 并/或把自由内径放到 φ150–155，或改用可开合铰链结构。
3. **本报告未覆盖**：钢丝与碗的接触应力/局部压痕、焊缝疲劳、眼环孔的磨损、手柄胶接强度、塑料件蠕变——这些需要非线性接触有限元与实物试验。
4. **建议的后续仿真**：
   - 非线性接触 FEA（ANSYS Mechanical / Abaqus / COMSOL / FreeCAD+CalculiX）：钢丝用 3D 实体或梁单元 + 自接触，做安装张开与承载两工况；
   - 多体动力学（Adams / RecurDyn / MuJoCo / Isaac Sim）：整机取放动作、倾覆与碰撞；
   - 疲劳（ANSYS nCode / Fe-Safe）：弹簧钢丝的 500~1000 次装拆；
   - 打印件：用 PA12 先做样件，按《3D打印说明》实测刚度与蠕变。
